# Waveshare ESP32-S3-Touch-LCD-4.3B Product Engineering Sample Program

[中文](README_ZH.md)

The ESP32-S3-Touch-LCD-4.3B integrates a 4.3B-inch capacitive touch screen and an audio module. 
It supports 2.4GHz WiFi and BLE 5 . It integrates large-capacity Flash and PSRAM. The on-board 4.3B-inch wide capacitive touch LCD screen can smoothly run GUI interface programs such as LVGL; 
Combined with various peripheral interfaces (such as CAN, I2C and RS485 interfaces), the ESP32-S3 HMI and other applications can be quickly developed.
