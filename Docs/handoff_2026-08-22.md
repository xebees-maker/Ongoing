## 가장 먼저 확인할 것

- **`git pull` 먼저.** 이 세션 끝에 아래 "Git" 절 커밋 전부 `origin/main`에 push 완료
  (force-push 아님, fast-forward될 것). 이번 커밋은 지난 세션(`handoff_2026-08-11.md`)
  이후 미커밋 상태로 쌓여있던 작업 전체를 한 번에 묶은 것 — 그만큼 diff가 큼(19파일,
  +1331/-222줄).
- **Cntl/CAM 둘 다 재빌드+재플래시 필요.** ESP-NOW 메시지(META_ACK 신설, 캡처 상태
  enum 확장 등)와 공용 헤더 상수(`ESP_NOW_NODE_UNPAIRED_RETRY_SEC`)가 바뀜.
- **Cntl 플래시는 앱 파티션만(`0x10000`) 권장** — assets 파티션을 같이 구우면
  `/assets/settings.bin`이 날아감(기존에 알려진 문제, `project_cntl_assets_partition_reflash`
  memory 참고). 이번 세션도 계속 앱 파티션만 구워서 검증함.
- **COM 포트는 항상 이 PC에서 새로 확인.** 마지막 확인값은 Cntl=COM18/CAM=COM5.
- **Cntl 통계탭 로그가 전부 영문으로 바뀜.** 로그 메시지 원문 68곳을 한국어→영문으로
  바꿨음(화면 표시 문구만, `ui_strings.h` 테이블 쪽 UI 텍스트는 안 건드림) — 시리얼
  로그나 통계탭 화면에서 이제 로그가 영문으로 나오는 게 정상.

## 오늘 한 일 요약

자세한 서술은 `한일_2026-08-22.txt` 참고. 핵심만:

1. 사진 가져오기 3002(청크 누락) — 진짜 코드버그. META를 reliable 1회 요청으로 바꾸고
   META_ACK(msg_type 45) 신설. NACK 라운드 off-by-one도 같이 수정.
2. 진행팝업이 이미 열려있을 때 재진입하면서 깨지던 버그(연결해제가 안 먹는 것처럼 보임)
   수정 — 여는 함수에 "이미 열려있으면 먼저 닫기" 가드.
3. 지금촬영 핸드셰이크를 RECEIVED→INIT_NEEDED→INIT_DONE→CAPTURING→SUCCESS/FAILED
   다단계로 재설계, 무선 타임아웃과 하드웨어(카메라 초기화/촬영) 타임아웃을 분리.
4. 페어링 회귀("한번에 안 되고 두번째에 됨") — 나이키스트 샘플링 관점으로 원인 규명:
   CNTL의 PAIR_REQUEST 재시도 구간이 CAM의 "명령 못 받는 시간(4.8초)"의 2배보다 짧았음.
   CAM/Sens 공용 상수 `ESP_NOW_NODE_UNPAIRED_RETRY_SEC=3` 신설, CNTL 재시도 횟수를 이
   상수 기반 계산식으로 변경(13회, ~6.5초 구간). 실기 확인 완료.
5. 5005(httpd_start 실패) — 근본원인은 내부(비-PSRAM) DRAM 고갈(`libmain.a` .bss가
   21KB, 특히 함수-로컬 static 버퍼들). 대형 정적버퍼 다수를 PSRAM으로 이전 +
   `httpd_config_t.task_caps`를 PSRAM으로 명시. Free internal DRAM 1.3KB대 → 15KB로
   개선 확인(실기 3회 측정).
6. 상황판 요약판넬에 웹 URL(1번째줄)/여유메모리 I=.../P=...(2번째줄) 상시 표시 추가.
   바이트값 자동단위+유효숫자4자리 포맷 함수(`format_bytes_human`) 신설.
7. **통계탭 로그 스크롤 성능 전면개선(오늘 메인 작업)** — 원인은 라벨 하나에 누적된
   최대 6KB 텍스트를 `LV_LABEL_LONG_WRAP`으로 매번 커스텀 TTF 폰트 기준 재측정하던 것.
   로그 메시지 전부 영문화(68곳) → LVGL 내장 비트맵 폰트(Montserrat 20pt, 일반/전력
   로그 통일) 사용 가능해짐. wordwrap 완전 제거, 대신 앱 코드가 직접 폭을 재서 넘치는
   줄만 "..."로 잘라 저장(`trim_to_width`/`trim_multiline_to_width`, `ui_main.c`).
   타임스탬프도 공용 함수(`ui_log_format_timestamp`, `ui_log.c`)로 통일. 실기 확인:
   "아주 다 잘 동작해"(사용자) — 단 "..." 트림은 마침 긴 줄이 없어서 미확인 상태.
