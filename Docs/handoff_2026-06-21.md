- 로컬 `sdkconfig` 둘 다 STA로 전환, SSID/비번은 `iptime2.4`/(사용자 제공값)로 설정 — gitignore라 git에는 안 올라감.

### 4. TinyTTF kerning 버그 재발 — 이번엔 git으로 추적되는 자동 패치로 고정
- 6/16에 고쳤던 `managed_components/lvgl__lvgl/.../lv_tiny_ttf.c` 패치(kerning_cache 잘못 release, NONE/NORMAL 조건 반전)가 `managed_components`가 gitignore 대상이라 컴포넌트 매니저가 재fetch하면서 그대로 날아갔던 게 재발 — "노드" 탭에 IP 텍스트 추가하면서 자간 깨짐으로 발견됨.
- `Cntl/patches/fix_tiny_ttf_kerning.py` 작성 — 두 버그 패턴을 멱등적으로 재적용(이미 패치돼있으면 손 안 댐). `Cntl/CMakeLists.txt`의 `project(startup)` 직후에 매 configure마다 자동 실행되도록 `execute_process` 추가.
- 일부러 버그를 재현시켜서(`lv_cache_release(dsc->glyph_cache, ...)`로 되돌림) `idf.py reconfigure` 한 번으로 자동 재패치되는 것까지 실제로 검증함.
- **주의**: 패치 스크립트의 print는 전부 ASCII만 사용 — Windows에서 CMake `execute_process`가 콘솔 코드페이지로 stdout을 받기 때문에, 한글을 출력하면 `UnicodeEncodeError`로 configure가 중간에 죽는 걸 한 번 겪었음. 이 스크립트(`patches/` 아래)에는 앞으로도 비ASCII 문자를 넣지 말 것.
