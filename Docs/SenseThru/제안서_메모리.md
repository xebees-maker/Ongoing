**현재 단계: 3종 모두 초안.** 새 PC가 망가져 있던 동안 개발 PC에서 임시로 만든 문서다. 내용·형식 모두 확정된 게 아니다.

**작성 방법:**
1. **제품소개서를 중심**으로 쓴다.
2. 쓰다가 필요한 **기술 설명은 기술소개서**로 보충한다.
3. **비전 이야기는 회사소개서**로 보충한다.
4. **Claude의 역할:** 제품소개서를 쓰는 도중에, 적절한 시점에 "이 내용은 기술소개서로 / 회사소개서로 넣으면 좋겠다"고 **먼저 팁을 준다** (사용자 요청, 2026-11-24).

**문체 주의 (사용자 지적, 2026-11-24):**
- 제품소개서는 말(글)이 너무 많으면 안 된다. **그림이 들어가고 직관적**이어야 한다. 쪽마다 그림이 주인공, 글은 짧게.
- Claude가 쓰면 특히 기술소개서가 **논문이나 과제 완료 보고서처럼** 되는 경향이 있다.
- 기술 문서라도 **소개서**다. 읽는 사람이 "이 기술이 무엇을 해 주는가"를 알아보게 쓰고, 연구 결과를 보고하는 식으로 쓰지 않는다.
- 기술소개서 각 쪽은 "그래서 현장에서 무엇이 좋아지는가"를 먼저 말하고, 구현 내용은 그 근거로 짧게 붙인다. (사용자 동의)
- **제품소개서는 현재 너무 딱딱하다.** 세일즈 포인트가 드러나고 스토리텔링이 되도록 고친다.

**제품의 핵심 차별점 (사용자, 2026-11-24):**
- 기술적 강점은 고가용성 / 검증된 하드웨어 / 유연한 확장 구조 / 에러에 강함 등이 있다.
- 그러나 **기존 스마트팜과 비교하면 "무선"이 가장 큰 특징**이다. 제품소개서의 중심 세일즈 포인트.
- 무선은 두 구간 모두:
  1. **노드끼리의 연결** (측정기·카메라 ↔ 무선확장기 ↔ 중앙제어기)
  2. **중앙제어기(콘)의 외부 연결: 무선 IoT 셀룰러** 지원. 광대역 Wi-Fi가 있으면 그걸 쓸 수도 있음.
     - 기술적으로는 MQTT 서버를 이용한다.
     - 셀룰러는 2026-11-24 기준 테스트 중. 사용자 판단: 제품소개서에서는 "지금 된다"고 보고 쓴다.
- **결과(기술적·경제적 관점):** 도입비와 유지비가 저렴하고, 확장이 쉽다.
- **농부 관점:**
  1. 처음엔 간단히 시작해서, 나중에 전문 수준의 관제 시스템으로 갈 수 있다.
  2. 측정 자료가 통계로 남아, 나중에 **농부가** 스스로 학습하고 재배를 개선하는 자료로 쓸 수 있다. (주체 = 농부, 확인됨)
     - 현재: 온습도, 이산화탄소, 암모니아 **통계만** 제공. 이 기능은 아직 부족하다.
     - 필요: 통계 자료에 **노트(메모)**를 달 수 있어야 한다. 그때 무슨 일이 있었는지 — 예: 관수를 안 했다, 환기를 덜 했다/너무 했다 등. (아직 미구현)
     - 필요: **재배 차수** 개념. 그래프만 봐도 이전 차수와 어떻게 다른지, 내일은 무엇을 준비해야 하는지 알 수 있으면 좋다. (아직 미구현)
  3. 향후 AI 기능으로 편리해지고 시간이 절약되어 **여유로운 생활**을 할 수 있다. (표지 문구 "농가에 여유를 심다"와 연결)
- 현재 sales.html 14쪽은 "재배사 밖에 Wi-Fi와 인터넷이 있어야 합니다"라고 되어 있어 위와 맞지 않음 → 고칠 것

**확인된 사실 (브레인스토밍 관련):**
1. 이 시스템은 팬, 가습기, 보일러를 **제어만** 한다. 설비를 설치하지 않는다 (농가의 기존 설비를 그대로 씀).
2. 릴레이 구성:
   1. **로컬 릴레이 2개** (중앙제어기): 전력 제어 기능 있음.
   2. **원격 릴레이**: 계속 늘릴 수 있음. 전력 제어도 되고, On/Off만 할 수도 있음.
   3. 예: 보일러는 원격 릴레이로 On/Off만 해도 제어됨. 팬은 전력 제어로 다룸.
3. 설비 연결은 **플러그를 꽂기만 하면 된다** → "설치 기사 없이 설치 가능"을 쓸 수 있음.
4. 설치: 설치 기사 없이 **혼자 해도 되고**, 원하면 **설치 서비스(유료)**를 받아도 된다. "설치 기사가 필요 없다"와 "설치 서비스를 판다"는 다른 얘기.
5. 원격제어장치 수: 원하는 만큼(문서 표현). 기술적 한계는 무선 대역폭이라 아주 많이 붙일 수 있다.
6. "소프트웨어만 딸깍하면 기능 확장"의 뜻: 펌웨어 업데이트가 아니라, **새 하드웨어 장치를 붙일 때 중앙제어기(콘)에서 접속을 허용하기만 하면 기능이 확장된다**는 것.
