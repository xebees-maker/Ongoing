현재 설계 한도와 개선 과제

아래 한도는 코드와 메모리 설계에서 정한 값으로, 하드웨어의 한계가 아닙니다.

현재 설계 값

  • 브리지 2대
  • 보드 8, 센서 12, 측정값 16
  • 배지 온도 3, 카메라 2, 나머지 종류 각 1
  • 보드당 센서 4, 채널 5

보안

  • 웹은 로그인과 시도 제한을 적용
  • 노드 무선 구간은 현재 암호화하지 않음
  • 푸시 알림은 암호화 없는 HTTP로 전송

확인과 측정 과제

  • 배터리 사용 시간 실측
  • CO2 외 종류의 교체 시나리오 시험
  • SD 쓰기 보호와 이중화의 장기 효과 확인

제품화 과제

  • 개발용 시험 API 제거
  • 방폭 등 위험 구역 인증 검토
  • 3대 이상 브리지와 측정값 확대
